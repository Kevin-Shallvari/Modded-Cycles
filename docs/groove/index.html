8 track M:C

Model:Groove — a derived Model:Cycles OS 1.13 whose only goal is eight audio tracks instead of six. Nothing from the mods page is included.

Model:Groove — un OS dérivé du Model:Cycles 1.13 dont le seul but est de passer à huit pistes audio au lieu de six. Rien de la page des mods n'y est inclus.

Read this first

  • Experimental. The pattern format is proven in emulation; the kit is not. The kit is verified byte by byte, not proven.
  • A bank is traded. 80 patterns instead of 96 — bank F is exchanged for tracks 7–8. This is the mod's only data loss.
  • Your existing projects will be refused. Cleanly: nothing is erased, and restoring the official OS brings everything back.
  • Tracks 7–8 are selectable from the track menu (the menu now lists eight, and the index bounds follow). Kevin's page 2 — pads T1–T2 lighting only LEDs 1–2 — is not written yet, so the display is still the six-track one.
  • Rule deviation, stated plainly: this repo's rule is that unproven code does not go in a flasher. The owner has overruled it for this page.
  • Expérimental. Le format de pattern est prouvé en émulation ; le kit ne l'est pas. Le kit est vérifié octet par octet, pas prouvé.
  • Une banque est échangée. 80 patterns au lieu de 96 — la banque F contre les pistes 7-8. C'est la seule perte de données du mod.
  • Vos projets existants seront refusés. Proprement : rien n'est effacé, et remettre l'OS officiel les rend lisibles.
  • Les pistes 7-8 sont sélectionnables depuis le menu de pistes (le menu en propose huit, et les bornages suivent). La page 2 de Kevin — pads T1-T2 n'allumant que les LEDs 1-2 — n'est pas encore écrite : l'affichage reste celui de six pistes.
  • Écart à la règle, dit franchement : la règle du dépôt est que du code non prouvé ne va pas dans un flasher. Le propriétaire l'a écartée pour cette page.

1 — Your official file

2 — Build and check

Two tweaks are applied: groove-8tracks (the engine) then groove-patterns (the format). The result is checked against the expected MAIN OS; if it differs, nothing is sent.

Deux tweaks sont appliqués : groove-8tracks (le moteur) puis groove-patterns (le format). Le résultat est comparé au MAIN OS attendu ; s'il diffère, rien n'est envoyé.

3 — Send over USB

The machine must be on its STARTUP MENU (hold [FUNC] while powering on), as for any OS update. If anything goes wrong, the STARTUP MENU restores the official OS.

La machine doit être sur son STARTUP MENU (maintenir [FUNC] à l'allumage), comme pour toute mise à jour. En cas de problème, le STARTUP MENU remet l'OS officiel.

What to look for

  • Does it boot, and does it complain about the current project?
  • Can you reach the browser and create a new project?
  • Do tracks 1–6 sound exactly as before?
  • Do tracks 7–8 exist, play, and stay silent without a trig?
  • Try to load an original project: is it refused cleanly, with nothing erased?
