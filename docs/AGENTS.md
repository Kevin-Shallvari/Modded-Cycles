# AGENTS.md — docs/

The GitHub Pages site, served from `main`: <https://18nelli18.github.io/Modded-Cycles/>. Static files, no build step,
no framework. Read the root [`AGENTS.md`](../AGENTS.md) first. Procedures:
[`flasher-integration`](../.agents/skills/flasher-integration/SKILL.md) (cards, generated blocks, web checks) and
[`bilingual-user-docs`](../.agents/skills/bilingual-user-docs/SKILL.md) (guide, release notes, texts, stamp).

```
index.html             home page (intro, mods, "what's new" from release.js)
flasher/index.html     the web flasher page
flasher/app.js         its UI: texts (en/fr), FEAT feature texts, the OS header and rows, REF_MAINOS and REF_MODS (generated blocks), flashing steps
flasher/builder.js     builds the .syx in the browser (port of tools/build.py + mtlib)
flasher/flasher.js     .syx checks, Web MIDI sending: classic (CONFIG › UPGRADE) and fast (Transfer protocol, notes/37)
flasher/tweaks.js      GENERATED by tools/gen_flasher_tweaks.py from os.json + tweaks/ — never edit by hand
guide/index.html       the user guide, one numbered <section id="…"> per feature (the anchor is the feature's `guide` in os.json)
assets/release.js      MC_RELEASES: flasher versions, newest first (English posted to Discord after merge)
assets/site.js, site.css, guide.css, cycles.js   shared behaviour and styles (language, theme)
```

## Local invariants

- Every visible text exists in English and French, side by side; French says « vous ».
- `REF_MAINOS` / `REF_MODS` in `app.js` and `tweaks.js` are generated: rerun `tools/ref_mainos.py` and
  `tools/gen_flasher_tweaks.py`, never edit or hand-merge them.
- `builder.js` stays byte-equivalent to `tools/build.py`; `flasher.js` validates like `tools/mtlib/syx.py`.
- Works from `file://` and under GitHub Pages: no `fetch` of local files, relative script paths. Users' files never
  leave the browser.
- Bump the `YYYY-MM-DD-NN` stamp (`window.MC_BUILD` and every `?v=` of the three pages) with any page or script change.
- The home page list (`ol.mods`, `data-hl` controls, `data-lcd` screen text) is a short selection of the OS: ask Maxime
  before adding to it.
- Step 1 of the flasher is read-only: one firmware, the OS of `os.json`. Nothing to tick, no per-mod rules in the page.
