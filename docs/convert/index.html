Wavetable converterConvertisseur de tables d'ondes

Turn a wavetable into a file the Wave machine plays on your Model:Cycles. Drop your WAV — or a whole folder, whose subfolders are kept — then download the result or send it straight to the machine.Transformez une table d'ondes en un fichier que la machine Wave joue sur votre Model:Cycles. Déposez votre WAV — ou tout un dossier, dont les sous-dossiers sont gardés — puis téléchargez le résultat ou envoyez-le directement à la machine.

Mono, 2048 points per frame, one cycle per frame. Drop one file, several files or a whole folder: you get a ZIP that keeps the subfolders.Mono, 2048 points par trame, un cycle par trame. Déposez un fichier, plusieurs fichiers ou tout un dossier : vous recevez un ZIP qui garde les sous-dossiers.

The page switches the machine to Model:Samples mode for the transfer and back afterwards. If a transfer was cut off:La page passe la machine en mode Model:Samples pour l'envoi, puis la remet. Si un envoi a été interrompu : (restarting the machine does the same).(redémarrer la machine fait de même).

What it doesCe qu'il fait
It removes the fold-back on high notes by baking in quieter, shorter copies of your table, and labels the file 48 kHz so Transfer leaves it untouched. Nothing is computed on the machine.Il supprime le repliement dans les aigus en gravant dans le fichier des copies plus douces et plus courtes de votre table, et l'étiquette 48 kHz pour que Transfer n'y touche pas. Rien n'est calculé sur la machine.
RequirementsPrérequis
A mono WAV whose length is a whole number of 2048-point frames (Serum, Vital, most wavetable packs). Files from Elektron Transfer are fine if they were already 48 kHz.Un WAV mono dont la longueur est un nombre entier de trames de 2048 points (Serum, Vital, la plupart des packs). Les fichiers venant d'Elektron Transfer conviennent s'ils étaient déjà en 48 kHz.
Your files stay on your computerVos fichiers restent sur votre ordinateur
Everything runs in the browser; nothing is uploaded.Tout se passe dans le navigateur ; rien n'est envoyé.
