# AGENTS.md — tweaks/

One folder per device and OS (`model-cycles_OS1.13/` is the only one). Read the root [`AGENTS.md`](../AGENTS.md)
first. Field reference, file numbering and the generator loop: skill
[`tweak-generators`](../.agents/skills/tweak-generators/SKILL.md) and its
[`references/tweak-format.md`](../.agents/skills/tweak-generators/references/tweak-format.md).

## Local invariants

- **Never edit a tweak JSON by hand.** Each one is written by its generator (named in the last line of its
  `description`) and checked by `--check`. Exceptions: drumkilla's `01`–`03` (copied as-is, SHA-256 in
  `PROVENANCE.md`; `02` carries our 3-byte fix) and `10-6ch-multiout.json` (ms-multi-output's table).
- `NN-<id>.json`: `NN` is also `order`. Find the next free number with `ls`, and check open branches.
- `os.json` (repo root) says which tweaks are in the OS; this folder is the **library** of every tweak built and proven,
  including those outside the OS. A tweak that enters the OS must not share bytes with, conflict with, or require a
  tweak outside it (`tools/check_overlaps.py`, `tools/gen_flasher_tweaks.py --check`).
- `REGISTRY.md` is generated by `python3 tools/registry.py`; never edit it, commit it with the tweak that changes it.
- `device.json` holds the stock hashes and `cave_refs_ok`; add to it only with the reasoning in `why` and a note.
- `PROVENANCE.md`: one row per tweak or family, added in the same commit as the tweak.
- `LICENSE-*` files are the third-party texts the tweaks carry; the flasher serves copies in `docs/flasher/`.
